# 2-3 Minute Demo Video Flow

- **0:00 - 0:30 (Intro & Arch)**: Introduce the team, the problem, and quickly show the Architecture and ER Diagram to highlight backend robustness.
- **0:30 - 1:15 (Frontend Demo)**: Walk through creating a booking as a user. Emphasize user experience, picking an active slot, and receiving the unique reference code.
- **1:15 - 1:45 (Edge Cases & Backend)**: Show what happens when a user tries to book a full slot, book an expired offer, or double-book with the same phone number. Demonstrate the API blocking the request.
- **1:45 - 2:30 (Tests & Code Quality)**: Briefly show the test suite running (xUnit tests passing, specifically mentioning the concurrency/race-condition test). End with final thoughts and the impact of the solution.
