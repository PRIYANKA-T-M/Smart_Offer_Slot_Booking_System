# Frontend Screenshots Checklist

Ensure you capture the following states:
1. **Home/Offer List**: Display active offers.
2. **Offer Details**: Show slots with capacities.
3. **Booking Form**: Show customer entering name and phone.
4. **Validation Error**: Capture an error toast (e.g. "Slot is full").
5. **Success Confirmation**: Capture the booking success screen with unique reference number.
